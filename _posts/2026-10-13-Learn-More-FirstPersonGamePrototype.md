# Project Overview

First Person Game Prototype is a open source single player prototype that showcases mechanics that could be added to any unreal engine projects. Some of these mechanics include procedural terrain generation, bullet particle effects, portal teleportation, and bullets that could alter terrain.  

# Project Details

- Download: [Play The Game](https://justin-bytes-code.itch.io/first-person-game-prototype-example)
- Github: [Source Code](https://github.com/Justin-Bytes-Code/First-Person-Game-Prototype)
- Platform: PC (Windows)
- Engine: Unreal Engine 5
- Language & Scripting: C++, Unreal Engine Blueprints
- Team Size: 1 (Solo Project)
- Role: Gameplay Programmer
- Development Period: 2 Months

# Responsibilities 

- Developing and Maintaing C++ Code
- Built a system in C++ that procedural generates terrain using Perlin noise that could be alter by the player's bullets and be adjusted in the editor.
- Created randomly generated bullet colors with particle effects and decals.  
- Created a portal system in C++ that aligns with the camera to teleport the player.
