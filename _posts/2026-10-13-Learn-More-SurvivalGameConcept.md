# Project Overview

Survival Game Concept is a open source single player proof of concept survival game that has all the common mechanics you see in a standard survival game recreated from scratch in Unreal Engine C++. 

# Project Details

- **Download:** [Play The Game](https://justin-bytes-code.itch.io/survival-game-concept)
- **Github:** [Source Code](https://github.com/Justin-Bytes-Code/Survival-Game-Concept)
- **Platform:** PC (Windows)
- **Engine:** Unreal Engine 5
- **Language & Scripting:** C++, Unreal Engine Blueprints
- **Team Size:** 1 (Solo Project)
- **Role:** Gameplay Programmer
- **Development Period:** 2 Months

# Responsibilities 

- Developing and Maintaing C++ Code
- Built a free form building system from scratch
- Create and implement UX and UI
- Implemented basic AI behavior for placeholder creatures.
- Implemented a Health, Hunger, and Stamina mechanic.
