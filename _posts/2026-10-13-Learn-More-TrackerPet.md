# Project Overview

Tracker Pet is an Android mobile application designed to help animal breeders manage and track information about their animals. It uses a local SQLite database to store animal records offline, allowing users to manage their data without requiring an internet connection.

# Project Details

- Download: [Download The App](https://github.com/Justin-Bytes-Code/Tracker_Pet/releases/tag/v1.0.0)
- Github: [Source Code](https://github.com/Justin-Bytes-Code/Tracker_Pet)
- Platform: Android
- Audience: Animal Breeders
- Frameworks & Technologies: Android, SDK SQLite, & Android Studio
- Language & Scripting: Java, SQL, XML
- Team Size: 1 (Solo Project)
- Role: Application Developer
- Development Period: 2 Months

# Responsibilities 

- Developing and Maintaining Java Code & SQL Database
- Create a Functional Login & Signup Feature 
- Create and implement UX and UI for users
- Create Notification placeholder support for a future feature where the app could send SMS messages. 
- Created a offline & local database. 
- Built an expandable database where users could add an infinite number of animals in the database. Other features the database has is: creating, deleting, and editing.
